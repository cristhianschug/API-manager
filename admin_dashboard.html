Mapeamento automático
Ao cadastrar o cliente, a plataforma lê o dicionário do Firebird, expõe todas as tabelas como endpoints /api/v1/data/{slug} e pede à IA o propósito, relacionamentos e filtros de cada uma. O Chat IA e o MCP consultam esse mapeamento para decidir qual endpoint chamar — nunca geram SQL. O acesso a cada tabela é liberado por API key.
