# Tenant Isolation

Status: DRAFT

## Non-negotiable invariant

`API credential → resolved tenant → authorized resources → tenant database`

The client must never choose the database.

## Isolation requirements

- tenant resolution occurs server-side;
- tenant/database mapping is controlled by the platform;
- database credentials are server-side secrets;
- connection pools are tenant-safe;
- connections must never be reused across tenants;
- cache keys must include tenant identity;
- authorization must be tenant-aware;
- logs must preserve tenant context without exposing secrets.

## Tenant Escape testing

Test attempts through:

- URL parameters;
- query parameters;
- headers;
- API keys;
- object IDs;
- cache;
- filters;
- pagination;
- connection reuse;
- route manipulation;
- concurrent requests.
