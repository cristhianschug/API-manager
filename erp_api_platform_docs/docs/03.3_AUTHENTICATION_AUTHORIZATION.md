# Authentication and Authorization

Status: DRAFT

## API authentication

Initial external API authentication:

`X-API-Key: <key>`

Raw API keys should be shown only once at creation and stored only as secure hashes.

## Authorization

Permissions should be granular.

Examples:

- `cliente.read`
- `produto.read`
- `estoque.read`
- `venda.read`

Authorization must evaluate:

1. identity;
2. tenant;
3. API key/application;
4. permission;
5. endpoint;
6. resource scope.
