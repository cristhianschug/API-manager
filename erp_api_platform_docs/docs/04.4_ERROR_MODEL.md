# Error Model

Status: DRAFT

## Response structure

```json
{
  "code": "RESOURCE_NOT_FOUND",
  "message": "Resource not found.",
  "request_id": "..."
}
```

## Rules

Never return:

- SQL;
- stack traces;
- filesystem paths;
- database credentials;
- internal topology;
- sensitive diagnostic data.

## Required categories

- authentication failure;
- authorization failure;
- tenant mismatch;
- validation failure;
- not found;
- conflict;
- rate limited;
- timeout;
- dependency unavailable;
- internal error.
