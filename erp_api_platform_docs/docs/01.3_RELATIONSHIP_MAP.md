# Relationship Map

Status: DRAFT

## Objective

Document PK/FK and inferred relationships without inventing semantics.

## Relationship template

`TABLE_A.COLUMN_A → TABLE_B.COLUMN_B`

For each relationship record:

- type: explicit FK / inferred
- cardinality if known
- evidence
- confidence
- API implications

## Critical principle

A relationship in the database does not automatically mean both entities should be exposed publicly.
