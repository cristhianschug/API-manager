# Threat Model

Status: DRAFT

## Threats

- SQL injection
- IDOR
- tenant escape
- privilege escalation
- API key theft
- API key replay
- rate-limit bypass
- path traversal
- cache poisoning
- sensitive data exposure
- denial of service
- abusive tenant
- compromised API instance

## Required treatment

Each threat must have:

- attack path;
- impact;
- likelihood;
- preventive control;
- detective control;
- test;
- residual risk.
