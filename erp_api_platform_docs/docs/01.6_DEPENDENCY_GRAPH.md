# Dependency Graph

Status: DRAFT

## Objective

Model dependencies between tables and database logic.

Example:

`VENDA → TRIGGER_VENDA_ESTOQUE → PROCEDURE_ATUALIZA_ESTOQUE → ESTOQUE`

## Required analysis

Identify:

- direct dependencies;
- transitive dependencies;
- mutation chains;
- cyclic dependencies;
- high-impact objects;
- objects that can alter financial or stock data.

## API implication

A public endpoint must consider downstream effects, not only its direct table.
