# API Key Model

Status: DRAFT

## API key properties

A key should have:

- identifier;
- secure hash;
- tenant;
- application/client;
- permissions;
- status;
- creation timestamp;
- expiration/revocation state;
- last-used metadata where appropriate.

## Security

Never store raw keys unnecessarily.

Never log full keys.

Revoked keys must stop authorizing requests according to the platform's cache invalidation guarantees.
