# Glossary

| Term | Definition |
|---|---|
| API | Application Programming Interface |
| API Key | Credential identifying an authorized application/client |
| Control Plane | Administrative/configuration layer |
| Data Plane | Request execution layer |
| Tenant | Isolated ERP customer/environment |
| DTO | Data Transfer Object |
| FDB | Firebird database file |
| PK | Primary Key |
| FK | Foreign Key |
| Trigger | Database event-driven logic |
| Procedure | Stored procedural database logic |
| Function | Database function that returns a value |
| View | Stored query abstraction |
| Generator/Sequence | Database object used to generate values |
| OpenAPI | Machine-readable API contract |
| Swagger UI | Interactive OpenAPI documentation/testing interface |
| IDOR | Insecure Direct Object Reference |
| RPS | Requests per second |
| P50/P95/P99 | Latency percentiles |
| Hot path | Code executed for normal request processing |
| Schema Catalog | Inventory of database structures |
| Business Rule | Behavior required for correct ERP operation |
| Tenant Escape | Any path that allows one tenant to access another tenant's data |
